# Portal Filosófico da Névoa

Portal educacional interativo de Filosofia e Ciências Humanas com estética Halloween, jogos, desafios, XP e aventuras.

## Vídeos do Gemini
Envie os MP4 para `assets/videos/` com estes nomes exatos:

- `guia_da_nevoa.mp4`
- `mansao_da_nevoa.mp4`
- `guardiao_dos_filosofos.mp4`
- `espelho_guardiao_sombrio.mp4`

Enquanto os vídeos não estiverem presentes, o portal mostra as artes estáticas normalmente.

## GitHub Pages
Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/(root)`.
