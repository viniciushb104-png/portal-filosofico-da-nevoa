# Assets do Oráculo Pedagógico

Coloque os sprites PNG com transparência nesta pasta, usando exatamente estes nomes:

- oraculo-observando.png
- oraculo-falando.png
- oraculo-pensando.png
- oraculo-surpresa.png
- oraculo-aprovando.png
- oraculo-misteriosa.png

A página já está programada para trocar automaticamente os estados:
observando -> pensando -> falando -> aprovando, além de surpresa e misteriosa.

Se algum arquivo ainda não existir, o site usa uma esfera mágica como fallback e continua funcional.

Direção visual: Oráculo feminina, cabelos lilás/prateados, chapéu roxo com lua e estrelas, acabamento anime 2D mágico de Halloween, fundo transparente.
